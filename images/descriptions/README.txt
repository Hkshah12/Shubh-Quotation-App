Put your PRODUCT DESCRIPTION images here (spec sheets / big product photos).

Then in data/catalog.csv, add the file name in the "descimage" column for that item,
e.g.  centrifuge_desc.jpg

In the app, tick the "Desc" checkbox on a line item to append its description image
on fresh full-width page(s) after the quotation (in both the PDF and the Word file).
